STEP-BY-STEP PHONE-ONLY SETUP

1. Upload Website:
   - Open GitHub.com / Netlify.com on phone
   - Create new repo / site
   - Upload index.html + super11.apk
   - Enable GitHub Pages / Netlify live URL

2. Cashfree Payment:
   - Open Cashfree.com on phone
   - Create Payment Link
   - Website URL: Use your live GitHub/Netlify link
   - Copy link
   - Replace YOUR_CASHFREE_PAYMENT_LINK in index.html

3. Admin + Referral:
   - Open Google Sheets
   - Create 3 sheets: USERS, PAYMENTS, WITHDRAW
   - Track wallet, referral, payments manually
   - Update bonus / withdraw status

4. APK Installation:
   - AppsGeyser / WebIntoApp → Website URL → Build APK → Download
   - Name: super11.apk
   - Website folder me upload
   - Users click Download → Install APK
   - New version: Build again → Replace APK → Users update

5. Website PRO Tips:
   - Mobile first
   - Download + Payment + Referral buttons prominent
   - 18+ disclaimer
   - Restricted states warning
   - Feature list visible
